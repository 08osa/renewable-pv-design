# Grid-Connected PV System Design - Riyadh Residence

Renewable-energy term paper: design and economic evaluation of a grid-connected rooftop photovoltaic system for a residential house in Riyadh, Saudi Arabia.

Topics covered: solar potential of Saudi Arabia and Vision 2030, panel/inverter selection (LONGi monocrystalline panels, Huawei inverter), string configuration and cable sizing per SEC/IEC standards, yield estimation with NREL **PVWatts**, and payback/NPV and CO2 analysis.

The paper and supporting PDFs are not published in this repository.
